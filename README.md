# Лабораторна робота №4: Node.js & Express. Робота з API та динамічними шаблонами

## Опис проекту
Метою роботи є опанування навичок створення серверних додатків на платформі **Node.js**, налаштування маршрутизації за допомогою фреймворку **Express**, робота з шаблонізатором **Handlebars (HBS)** та інтеграція з зовнішнім API для отримання актуальних даних про погоду в реальному часі.

*Завдання:* Розробити вебдодаток для відображення прогнозу погоди. Реалізувати вибір міст зі списку, автоматичне визначення місцезнаходження через Geolocation API та динамічне виведення метеоданих (температура, вологість, тиск, іконки стану).

## Структура проекту
* `app.js` — головний файл сервера, логіка маршрутизації та запитів до API.
* `views/` — папка з основними шаблонами сторінок (`index.hbs`, `weather.hbs`, `error.hbs`).
* `public/css/style.css` — зовнішній файл стилів.

---
## Технічні характеристики
* **Платформа:** Node.js (v22.9.0).
* **Фреймворк:** Express.js.
* **Шаблонізатор:** Handlebars (HBS).
* **Зовнішнє API:** OpenWeatherMap (Current Weather Data).
* **Бібліотеки:** `request` (для HTTP-запитів), `path`, `hbs`.
---

## Функціональні можливості
Згідно з технічним завданням, додаток реалізує наступну логіку:

### Маршрутизація (Routing)
| Маршрут | Опис |
| --- | --- |
| `/` | Головна сторінка з меню вибору міст та інформацією про автора. |
| `/weather/:city` | Динамічний маршрут для отримання погоди за назвою міста. |
| `/weather?lat=X&lon=Y` | Маршрут для отримання погоди за географічними координатами. |
| `*` (Middleware) | Універсальна сторінка помилки 404 для неіснуючих шляхів. |

## Виконані кроки

### **1. Налаштування оточення:**
* Виконано ініціалізацію проекту командою `npm init`.
* Встановлено необхідні пакети: `npm install express hbs request`.
* Налаштовано середовище виконання та перевірено запуск сервера на порту 3000.

### **2. Розробка серверної логіки (`app.js`):**
* Налаштовано Express для роботи з папками `public` (статика) та `views` (шаблони).
* Зареєстровано `partials` для використання єдиного Header та Footer на всіх сторінках.
* Реалізовано логіку запитів до API OpenWeatherMap з використанням особистого ключа (API Key).
* Налаштовано обробку помилок (невірне місто, неактивний ключ, відсутність зв'язку).

### **3. Робота з API та Geolocation:**
* Організовано отримання даних у форматі JSON та їх парсинг для виведення в шаблон.
* Реалізовано підтримку локалізації (`lang=ua`) та метричної системи одиниць.
* Додано клієнтський JavaScript у `index.hbs` для взаємодії з **Browser Geolocation API**, що дозволяє автоматично передавати координати користувача на сервер.

### **4. Шаблонізація та Дизайн:**
* Створено динамічні шаблони з використанням синтаксису `{{ }}` для виведення змінних.
* Реалізовано адаптивний інтерфейс у стилі **Dark Mode**, що відповідає сучасним стандартам UX/UI.
* Налаштовано динамічне завантаження іконок погоди з серверів OpenWeatherMap у високій роздільній здатності (@4x).

## Як запустити

1. Переконайтеся, що на ПК встановлено **Node.js**.
2. Скопіюйте файли проекту в робочу директорію.
3. У терміналі виконайте команду `npm install` для завантаження залежностей.
4. Вкажіть дійсний `apiKey` у файлі `app.js`.
5. Запустіть сервер командою `node app.js`.
6. Відкрийте браузер за адресою `http://localhost:3000`.
