# Лабораторна робота №2: PHP & MySQL. Реалізація CRUD-операцій та сортування даних

## Опис проекту
Метою роботи є розширення функціоналу вебсайту шляхом впровадження можливостей створення, редагування та видалення записів у базі даних (CRUD), а також реалізація динамічного сортування списку статей.

*Варіант №9:* Спроектувати базу даних про авторів web-сайту і їх статтях: ім'я, адреса, обліковий запис, пароль, тема, заголовок, текст статті, ілюстрації.
---
## Структура проекту
* `db.php` — файл для встановлення з'єднання з сервером MySQL.
* `index.php` — головна сторінка зі списком усіх статей (використовує SQL JOIN).
* `newnote.php` — форма створення нової статті з випадаючим списком авторів.
* `editnote.php` — форма редагування існуючої статті.
* `updatenote.php` — обробник оновлення даних (UPDATE).
* `addnote.php` — обробник додавання даних (INSERT).
* `deletenote.php` — скрипт для видалення статей (DELETE).
* `details.php` — сторінка для перегляду повної інформації про конкретну статтю (реалізує обмін даними через GET).
* `style.css` — зовнішній файл стилів для оформлення інтерфейсу.
* `images/` — папка з ілюстраціями до статей.
---
## Технічні характеристики
* **Локальний сервер:** XAMPP.
* **База даних:** MySQL (MariaDB).
* **Порт MySQL:** 3307 (налаштовано через конфлікт стандартного порту 3306).
* **Мова розробки:** PHP

## Виконані кроки
### **Керування даними (CRUD):**
* **Створення (Create):** Реалізовано форму додавання статей, де поле `author_id` заповнюється динамічно через випадаючий список `<select>` на основі таблиці `authors`.
* **Читання (Read):** Оновлено головну сторінку для відображення скороченого тексту статей та кнопок швидкого доступу до адміністрування.
* **Редагування (Update):** Впроваджено механізм завантаження поточних даних у форму для модифікації та збереження змін за допомогою SQL-оператора `UPDATE`.
* **Видалення (Delete):** Додано функціонал видалення записів за `id`. Для безпеки впроваджено JavaScript-підтвердження дії `(confirm)`.

### **Сортування:**
* Реалізовано динамічне сортування списку статей за трьома параметрами: заголовком, автором та темою.
* Використано метод `GET` для передачі параметрів сортування та "білий список" (white-list) для захисту від SQL-ін'єкцій у запитах `ORDER BY`.
* Створено таблицю `articles` для зберігання контенту сайту та ілюстрацій.

### **Розробка та логіка:**
* Для обробки текстових даних використано функцію `mysqli_real_escape_string` (захист від помилок при наявності лапок у тексті).
* Використано `header("Location: ...")` для автоматичного перенаправлення користувача після успішного виконання операцій запису або видалення.

### **Дизайн:**
* Оформлення інтерфейсу винесено в окремий зовнішній файл **`style.css`** для забезпечення єдиного стилю на всіх сторінках сайту та оптимізації коду.
* Додано стилізацію для кнопок дій (Редагувати/Видалити) та панелі сортування.

## Як запустити

1. Скопіюйте папку проекту в директорію `C:/xampp/htdocs/`.
2. Імпортуйте базу даних `lab1.sql` через `phpMyAdmin` (або створіть таблиці за описом вище).
3. Переконайтеся, що в `db.php` вказано вірний порт (3307) та облікові дані користувача.
4. Відкрийте браузер та перейдіть за адресою `http://localhost/назва_папки/index.php`.
5. Використовуйте кнопку `+ Додати нову статтю` для наповнення бази.
6. Для зміни або видалення скористайтеся відповідними кнопками у картках статей.
