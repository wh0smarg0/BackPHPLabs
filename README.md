# Лабораторна робота №6: GraphQL. Створення Schema GraphQL та Resolvers. Створення Query та Mutation.

## Опис проекту
Метою роботи є опанування технології **GraphQL** для побудови гнучкого API у середовищі **Node.js**. Проект демонструє перехід від традиційної REST-архітектури до використання мови запитів GraphQL, створення схем даних (SDL) та розробку резолверів для виконання CRUD-операцій у базі даних **MongoDB**.

*Завдання (Варіант №9):* Реалізувати GraphQL API для керування базою даних про авторів веб-сайту та їхні статті (ім'я, адреса, обліковий запис, пароль, тема, заголовок, текст статті, ілюстрації).

## Структура проекту
* `app.js` — головний файл сервера: ініціалізація **Apollo Server**, інтеграція з Express та налаштування Middleware.
* `article.js` — модель даних Mongoose (схема документів MongoDB).
* `views/index.hbs` — вебінтерфейс для візуалізації даних та швидкого переходу до GraphQL Sandbox.
* `public/css/style.css` — файл стилів інтерфейсу.

## Технічні характеристики
* **Платформа:** Node.js (v22.9.0).
* **Сервер GraphQL:** Apollo Server v4.
* **База даних:** MongoDB (локальний сервер).
* **ODM:** Mongoose.
* **Фреймворк:** Express.js (v5.2.1).
* **Інструменти тестування:** Apollo Sandbox (GraphiQL) та **Postman**.

## Функціональні можливості (GraphQL API)
Додаток реалізує повний цикл операцій через єдиний ендпоінт `/graphql`:

### Типи операцій (Schema)
| Тип | Назва | Опис |
| --- | --- | --- |
| **Query** | `getAllArticles` | Отримання списку всіх статей (з вибором конкретних полів). |
| **Query** | `getArticle(id)` | Отримання детальної інформації про статтю за її ID. |
| **Mutation** | `createArticle` | **Створення:** додавання нового автора та статті в БД. |
| **Mutation** | `updateArticle` | **Оновлення:** редагування існуючих полів документа. |
| **Mutation** | `deleteArticle` | **Видалення:** вилучення статті з бази за ідентифікатором. |

## Виконані кроки

### **1. Налаштування GraphQL сервера:**
* Встановлено пакети `@apollo/server` та `graphql`.
* Інтегровано **Apollo Server** у існуючий Express-додаток за допомогою Middleware.
* Налаштовано **CORS** та `body-parser` для коректної обробки запитів із зовнішніх інструментів, таких як Postman.

### **2. Проектування схеми (SDL):**
* Визначено тип `Article`, що суворо відповідає структурі Варіанта №9.
* Описано вхідні параметри для мутацій, включаючи обов'язкові поля (`String!`).

### **3. Реалізація резолверів (Resolvers):**
* Розроблено асинхронні функції для обробки запитів, що використовують методи Mongoose: `find`, `findById`, `create`, `findByIdAndUpdate` та `findByIdAndDelete`.
* Реалізовано обробку помилок (Error Handling) для випадків, коли запис за вказаним ID не знайдено.

### **4. Тестування та дослідження:**
* Проведено серію тестів у **Apollo Sandbox** для перевірки кожної операції CRUD.
* Виконано дослідження роботи API через **Postman** (POST запити на `/graphql` із тілом типу GraphQL), що підтвердило повернення даних у форматі JSON.

## Як запустити

1. Переконайтеся, що службу **MongoDB** запущено.
2. У терміналі виконайте `npm install`.
3. Запустіть сервер: `node app.js`.
4. Для візуального перегляду: `http://localhost:3000`.
5. Для тестування API: `http://localhost:3000/graphql`.
