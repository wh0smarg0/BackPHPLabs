# Лабораторна робота №5: Node.js. Робота з БД MongoDB. Додаток, що реалізує CRUD операції в БД.

## Опис проекту
Метою роботи є отримання навичок роботи з NoSQL базою даних **MongoDB** у середовищі **Node.js**, проектування схем даних за допомогою бібліотеки **Mongoose** та реалізація повного циклу керування даними (Create, Read, Update, Delete).

*Завдання (Варіант №9):* Спроектувати базу даних про авторів веб-сайту і їх статтях: ім'я, адреса, обліковий запис, пароль, тема, заголовок, текст статті, ілюстрації. Реалізувати вебінтерфейс для керування цими даними та окремий роут для видачі даних у форматі JSON.

## Структура проекту
* `app.js` — головний файл сервера, налаштування з'єднання з БД та маршрутизація.
* `models/article.js` — схема (модель) даних Mongoose для колекції статей.
* `views/` — папка з шаблонами сторінок (`index.hbs`, `add.hbs`, `edit.hbs`, `details.hbs`).
* `public/css/style.css` — файл стилів.

---
## Технічні характеристики
* **Платформа:** Node.js (v22.9.0).
* **База даних:** MongoDB Community Server (локально).
* **ODM:** Mongoose (для взаємодії з БД).
* **Фреймворк:** Express.js.
* **Бібліотеки:** `method-override` (для PUT/DELETE запитів), `hbs`, `express`.
---

## Функціональні можливості
Додаток реалізує повний перелік CRUD-операцій:

### Маршрутизація (Routing)
| Метод | Маршрут | Опис |
| --- | --- | --- |
| **GET** | `/` | Головна сторінка: список усіх статей із бази. |
| **GET** | `/articles/:id` | Детальний перегляд однієї конкретної статті. |
| **POST** | `/articles` | Створення: збереження нової статті в MongoDB. |
| **PUT** | `/articles/:id` | Оновлення: редагування існуючого запису. |
| **DELETE** | `/articles/:id` | Видалення: вилучення документа з колекції. |
| **GET** | `/api/articles` | **JSON API:** вивід усіх даних у форматі JSON. |

## Виконані кроки

### **1. Налаштування бази даних та оточення:**
* Встановлено та запущено **MongoDB Community Server**.
* Ініціалізовано проект та встановлено залежності: `npm install express mongoose hbs method-override`.
* Налаштовано асинхронне підключення до локальної БД `mongodb://127.0.0.1:27017/lab5_db`.

### **2. Проектування моделі даних (`models/`):**
* Створено схему `ArticleSchema`, яка чітко описує структуру документа згідно з Варіантом 9.
* Додано обов'язкові поля (`required`) та налаштовано типи даних для коректного збереження контенту.

### **3. Реалізація серверної логіки та CRUD:**
* Використано блоки `try...catch` для обробки асинхронних запитів до БД та запобігання падінню сервера.
* Реалізовано Middleware `method-override`, що дозволило використовувати методи **PUT** та **DELETE** безпосередньо в HTML-формах.
* Налаштовано динамічний роутинг за ідентифікатором запису (`req.params.id`) для редагування та видалення.

### **4. Розробка інтерфейсу та API:**
* Створено динамічні шаблони для виведення списку статей та окрему сторінку для читання повного тексту статті.
* Реалізовано **JSON Endpoint** для програмного доступу до бази даних.
* Оновлено дизайн: виправлено відображення "тегів" тем (заборонено перенос слів), додано підсвітку активних елементів та підтвердження видалення записів.

## Як запустити

1. Переконайтеся, що службу **MongoDB** запущено на вашому ПК.
2. У терміналі виконайте `npm install` для встановлення модулів.
3. Запустіть сервер командою `node app.js`.
4. Відкрийте браузер: `http://localhost:3000`.
