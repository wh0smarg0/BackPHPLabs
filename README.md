# Лабораторна робота №1: PHP & MySQL. Створення бази даних та виведення даних

## Опис проекту
Метою роботи є встановлення локального сервера, проектування бази даних для веб-сайту про авторів та їхні статті, а також реалізація динамічного виведення інформації на сторінку за допомогою мови програмування PHP.
**Варіант №9:** Спроектувати базу даних про авторів web-сайту і їх статтях: ім'я, адреса, обліковий запис, пароль, тема, заголовок, текст статті, ілюстрації.

## Структура проекту
* `db.php` — файл для встановлення з'єднання з сервером MySQL.
* `index.php` — головна сторінка зі списком усіх статей (використовує SQL JOIN).
* `details.php` — сторінка для перегляду повної інформації про конкретну статтю (реалізує обмін даними через GET).
* `style.css` — зовнішній файл стилів для оформлення інтерфейсу.
* `images/` — папка з ілюстраціями до статей.

## Технічні характеристики
* **Локальний сервер:** XAMPP.
* **База даних:** MySQL (MariaDB).
* **Порт MySQL:** 3307 (налаштовано через конфлікт стандартного порту 3306).
* **Мова розробки:** PHP

## Структура бази даних `LAb1`
Згідно з інструкціями, у базі створено дві таблиці зі зв'язком «один до багатьох»:

### Таблиця `authors` (Автори)
| Поле | Тип | Опис |
| --- | --- | --- |
| `id` | INT (PK, AI) | Унікальний ідентифікатор автора.
|
| `name` | VARCHAR(100) | Повне ім'я автора.
|
| `address` | VARCHAR(255) | Адреса проживання.
|
| `login` | VARCHAR(50) | Обліковий запис для входу.
|
| `password` | VARCHAR(255) | Пароль доступу.
|

### Таблиця `articles` (Статті)
| Поле | Тип | Опис |
| --- | --- | --- |
| `id` | INT (PK, AI) | Унікальний ідентифікатор статті.
|
| `author_id` | INT (FK) | Зовнішній ключ (зв'язок з `authors.id`).
|
| `topic` | VARCHAR(100) | Тема статті.
|
| `title` | VARCHAR(200) | Заголовок.
|
| `content` | TEXT | Повний текст статті.
|
| `illustrations` | VARCHAR(255) | Назва файлу зображення.
|

## Виконані кроки
1. **Інсталяція:** Встановлено пакет XAMPP та запущено модулі Apache та MySQL.
2. **Проектування:** Створено структуру БД у `phpMyAdmin`.
3. **Зв'язки:** Встановлено міжтабличний зв'язок `FOREIGN KEY` між таблицями `authors` та `articles` з параметрами `CASCADE`.
4. **Розробка:** * Реалізовано вибірку даних за допомогою `mysqli_query()`.
* Налаштовано динамічне формування посилань з передачею `id` через адресний рядок.
* Організовано виведення зображень з обмеженням розміру для адаптивного відображення.
5. **Дизайн:** Оформлення винесено в окремий CSS-файл для уніфікації сторінок.

## Як запустити

1. Скопіюйте папку проекту в директорію `C:/xampp/htdocs/`.
2. Імпортуйте базу даних `lab1.sql` через `phpMyAdmin` (або створіть таблиці за описом вище).
3. Переконайтеся, що в `db.php` вказано вірний порт (3307) та облікові дані користувача.
4. Відкрийте браузер та перейдіть за адресою `http://localhost/назва_папки/index.php`.
