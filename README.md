# Лабораторна робота №3: PHP & MySQL. Сторінка статистики та пошук інформації

## Опис проекту
Метою роботи є реалізація аналітичного інструментарію для веб-сайту: створення сторінки статистики з використанням агрегатних функцій SQL та розробка системи пошуку інформації за ключовими словами, шаблонами та часовими діапазонами.

*Варіант №9:* Робота з базою даних про авторів та їхні статті. Реалізація підрахунку активності авторів та гнучкого пошуку по контенту.

## Структура проекту
До існуючої структури додано нові модулі:
* `statistics.php` — сторінка аналітики (загальна кількість записів, активність за місяць, лідери за кількістю статей).
* `search.php` — функціонал пошуку інформації (за словом, шаблоном `*` та діапазоном дат).
* `index.php`,`style.css` — оновлені для підтримки нової навігації та відображення даних.

## Технічні характеристики

* **Локальний сервер:** XAMPP.
* **База даних:** MySQL (MariaDB).
* **Порт MySQL:** 3307.
* **Ключові функції PHP:** `getdate()`, `mktime()`, `mysqli_fetch_assoc()`.
* **SQL оператори:** `COUNT()`, `GROUP BY`, `ORDER BY`, `LIMIT`, `LIKE`, `BETWEEN`.

## Виконані кроки

### **Статистика сайту:**
* Реалізовано підрахунок загальної кількості авторів та статей за допомогою агрегатної функції `COUNT()`.
* Впроваджено алгоритм обчислення початкової та кінцевої дат поточного місяця через `mktime()` для звіту про нові записи.
* Налаштовано виведення останнього доданого запису за допомогою оператора `LIMIT 1`.
* Реалізовано пошук «найбільш продуктивного автора» через групування записів `GROUP BY` та сортування результатів підрахунку.

### **Пошук інформації:**
* **За ключовим словом:** Пошук за точним збігом заголовка статті.
* **За шаблоном:** Використання оператора `LIKE` (програмна заміна символу `*` на `%`) для знаходження частин слів.
* **У діапазоні:** Фільтрація статей за датами створення за допомогою оператора `BETWEEN`.

### **Дизайн та навігація:**
* На головну сторінку додано кнопки **"Пошук по сайту"** та **"Статистика"** з відповідними іконками та стилізацією.
* Реалізовано табличне виведення результатів пошуку для наочного відображення знайденої інформації.

## Як запустити
1. Переконайтеся, що в таблиці `articles` присутнє поле `created` з датами (YYYY-MM-DD).
2. Відкрийте головну сторінку та скористайтеся кнопкою **"Статистика"** для перегляду аналітики.
3. Використовуйте **"Пошук"** для тестування запитів (наприклад, `title*` або діапазон дат `2026-02-01` - `2026-02-28`).
